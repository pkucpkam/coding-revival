# Servlet Learning

Welcome to the **Servlet Learning** repository. This project is a workspace for practicing and learning Java Servlets, JSP, and related web technologies.

## Contents
- **docs-from-pkucpkam-learning/**: Learning materials, notes, and documentation for JSP and Servlets.
- **practice/**: Source code for various practice exercises and mini-projects.
- **docs/**: Additional lesson notes.

## Technologies Used
- Java
- Java Servlets
- JSP (JavaServer Pages)
- Tomcat
- Maven

## How to use
You can clone the repository and open the different practice projects in your IDE (like IntelliJ IDEA or Eclipse) to run and explore them.
